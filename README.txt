Menus & Courses V12 — correctif de séparation des courses par semaine.

Sauvegardez vos données JSON avant installation. Remplacez les fichiers GitHub Pages par ceux du ZIP, supprimez pdf-export.v11.js, puis ouvrez votre URL avec ?v=12.

Les ajouts manuels sont désormais associés à la semaine sélectionnée. Les ajouts anciens (V11) sans semaine identifiable restent préservés dans les sauvegardes, mais ne sont plus affichés automatiquement : ajoutez-les de nouveau si nécessaire.

Réinitialiser : conserve les favoris, masque les recettes et les ajouts manuels de la semaine. Actualiser depuis les menus : rétablit les ingrédients sans ressusciter les ajouts manuels supprimés.
