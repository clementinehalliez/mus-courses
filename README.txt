Menus & Courses — version configuration de la semaine

Déposer tous les fichiers à la racine du dépôt GitHub Pages.
Avant mise à jour, exporter une sauvegarde JSON.
Nouvel onglet : Configuration de la semaine (repas, durées, créneaux longs, portions).
Le bouton Réinitialiser est visible dans Menus. Il efface uniquement les repas affichés pour la semaine choisie.
Les sauvegardes JSON anciennes restent compatibles et reçoivent les paramètres initiaux.
Les données restent locales à chaque navigateur.
